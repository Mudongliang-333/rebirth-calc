1开荒主线（次元一 → 次元二 → 进阶）
  • 前期别怕 转生，转生是变强最快的路；靠转生约半天可到 次元二
  • 次元二升到 2 万级 再选觉醒职业（四个分支，强度已平衡，按喜好选）
  • 觉醒后穿上对应套装，把好词条转移过去，然后一路打 觉醒塔（72 层）
  • 次元一 1000 关后开启「感知」：感知期间锁状态，不能先输出再换经验
  • 成就奖励领了即生效；推关成就给力量（提攻击），推塔成就给小怪增伤，副本成就给精英增伤

2挂图与感知
  • 感知满后当层经验达到最大值；死亡 / 打副本不变，只有切图会变
  • 轮回后清除感知记录，需要重新感知
  • 挂图看的是「经验/分钟」，优先选最大收益关卡档位

3转生与神力加点
  • 转生只改善经验修正，输出与属性不变；转生后等级归 1
  • 判断标准：未来 24h 收益 > 转生后收益 → 不推荐转生
  • 神力加点按 经输比（经验 : 攻击）分配：加成 = 攻击×1.25、爆伤 = 攻击
  • 前期经验修正低，转生收益快；后期要算清楚再转（见本计算器「总览」判定）

4资源获取：广告 / 抽奖 / 兑换 / 爱发电
  • 进群拿兑换码；每天 40 个广告 看完，优先：奥法能量瓶（每天必看）、遗忘水看满
  • 商城广告前期优先技能宝箱，尽快开出核心技能
  • 次元碎片抽奖、异界碎片兑换、活动兑换按当版本公告走

5装备系统（词条是重点）
  • 装备等级 / 灵等级 → 强化 → 词条 → 附魔附灵 → 神作 → 套装 → 升星/封印
  • 宝石、虚空锻造、超限重铸属于中后期，先保证词条与套装位
  • 法师核心看法术加成；战士核心看物理必杀率 / 物理投射物

6技能与专精
  • 未觉醒只有 4 个主动技能框；觉醒后解锁觉醒 1 / 觉醒 2 技能
  • 技能粉尘在魔法兑换里换觉醒技能碎片与技能宝箱
  • 还原等级返灵魂，还原强化返技能碎片
  • 职业专精：红框优先级最高，可用遗忘水调整（广告每天免费 5 个）；推塔用输出专精，挂机切经验加成

7御灵 / 秘法 / 魔物
  • 御灵：书核心 + 秘法组合，魂印转换可换属性
  • 魔物：培养 → 装备 → 灵智 → 封印 → 觉醒 → 升格
  • 中后期主线：把魔物觉醒、匠魂（主属性替换为驭宠）做满

8进阶次元与副本
  • 次元三 → 混沌次元 → 次元四 → 停滞 → 灾厄 → 遗忘（异能 Ⅰ~Ⅴ / 虚无 Ⅰ~Ⅴ）→ 未知
  • 远古秘境、英雄挑战、恶魔塔 / 量子观测者 / 黑塔宫殿、雷电脊峰 / 余火灯塔 / 叩石之塔 / 照灵之塔
  • 13.0 新增：虚空蚀界、誓灭之境（四塔守护者、守护者试炼能量加点）

技高价值小技巧
通用技巧（6 条）
  • 钥匙一次用 20 把：与 10 天周期对齐，不要每天 1 把就刷
  • 创世刻痕每天打：解禁碑文每用一次都有提升，不是只在阶段突破时
  • 广告转碎片：魔物/秘法/觉醒技能/双倍毕业后全看碎片
  • 广告的远古钥匙/箱子：中期看碎片；后期需圣水（双经验附魔分解）时再看
  • 不要在线挂机：离线 3 倍；只转生头两天在线推层
  • 职业推荐「无脑神法」是主观建议，按自己玩的走
打 BOSS 的 HP 作业（血书 + 生命手册）
  • 除血书外全上输出书（投掷物、暴怒、武器、加成）
  • 装备附灵全洗攻击力或生命值；换投掷物皮肤
  • 虚空污染天赋书换生命天赋书，后期 2~4 本，共鸣与强化拉高
  • 龙血还原：攻速/冷却先满，神圣点到生命恢复 50%；1/5 龙血加体力（50 万龙血 → 10 万体力），剩加主属性；打不死改 2/5
  • 思路：用血量换输出时间
御灵书 / 秘法留存
  • 红色输出书都要留：物/法加成、物/法暴怒、攻速/冷缩之力、投射物、红武器书
  • 橙色后期只保留生命手册
  • 宠物装备：2 生命加成 + 1~2 输出词条（暴怒 / 物法加成）
魔物封印提升技巧
  • 把 6 个橙色魔物封印培养成 3×3（皆主属性加成）
  • 进阶路线：3×3 → 4×3，约需 108 精魄 + 若干魔物 + 800 碎片还原
混沌次元 vs 次元四（挂图选择）
  • 省流：混沌挂图超过 15 万层 → 去次元四
  • 刚好能落地 2.9 万层左右的次四时，可以先去混沌（感悟时间短）
  • 次四给的灵魂（升技能）与纯净之灵（升御灵）比混沌多

装备词条（战士毕业视角）
  • 毕业 = 6 件必杀装（多一件提高洗词条容错）
  • 武器：经验 / 攻击力 / 穿透；其他：经验 > 穿透 > 攻击力 > 物加
  • 白色词条：暴怒戒指 / 穿透手镯 / 加成
  • 腕甲白色词条必须暴怒（神作前上限 4%，神作后可洗到 5%）

  • 进化必须橙色魔物且 III 阶，消耗英雄挑战「进化核心」，进度 100% 触发形变
转生加点底线
  • 战士：必杀率 / 暴击率面板 100%；攻速、轮盘 100% 够
  • 法师：暴击率 100%、冷却 100%（神力点到 100 即可）
御器与广告优先级

  • 广告 5 项（红框）每日必看；双倍药水离线 24h 时用
  • 奥法瓶：6 阶 44%（大阶段 7）直接用，不用囤

进遗忘次元的三条件
  • 落地收益每天 300T 以上
  • 中途拿到创世武器并升满
  • 准备 3 本血天赋书（至少 2 本共鸣）
  • 50 万级后可以开始进遗忘
灵魂罐 / 灵魂瓶：转生不清零
  • 转生会清空技能等级，但灵魂罐 / 灵魂瓶转生不清零
  • 日常任务与抽奖拿到的灵魂罐 / 瓶，留到转生后使用，基本能直接拉起 30 级技能
  • 这是转生落地起步最快的方式
封印词条实测：法术技能加成优先于智力
  • 实测对比：2 法术技能加成 + 6 智力 比 1 法术技能加成 + 7 智力 伤害高约 1.75%
  • 数值：2法+6智 = 7.01FF；1法+7智 = 6.89FF（6.89 × 101.75% ≈ 7.01）
  • 结论：有法术技能加成还是要拿，别盲目堆智力加成

法职业与觉醒方向 法技能搭配 法碎片与粉尘 法属性养成与加点侧重 法法师套装路线（含 13.0 毕业套）

法职业与觉醒方向
  • 本体：地狱法师；觉醒前先进次元二、再 2 万级觉醒
  • 智法 = 冥界术士（主属性 智力）
  • 神法 = 祝圣教士（主属性 神圣）
  • 力法 = 秘术巫师（主属性 力量）
  • 血法 = 禁忌血法（主属性 体力）
  • 区别只在主属性 / 套装名称 / 技能形态，其他玩法基本一致

法技能搭配
  • 开局：天雷术 / 火球雨过渡（不建议强化）
  • 4 个技能框解锁后：沙暴飓风 / 天星地爆 / 异能审判 / 灵场
  • 觉醒后挂图：觉醒1 / 觉醒2 / 天星地爆 / 异能审判 / 灵场 / 怒法风暴
  • 觉醒后 BOSS：觉醒1 / 觉醒2 / 天星地爆 / 灵场 / 沙暴飓风（异能审判替换）/ 怒法风暴
  • 升级比例：未觉醒 地爆:沙暴 ≈ 1.5:1；觉醒后 觉醒2:觉醒1:地爆 = 4:2:1

法碎片与粉尘
  • 解锁沙爆 / 地爆后，一星碎片全分解
  • 二星只留 怒法风暴 / 异能审判；强化满后多余分解
  • 三星留 沙爆 / 地爆 / 灵场
  • 粉尘优先升满觉醒二技能

法属性养成与加点侧重
  • 优先：冷却 100% → 觉醒 100% → 法术暴击率（前期≥100%，毕业约 400%）
  • 必要神力：经验、攻击力、法术爆伤、法术加成；边角料加生命
  • 三维 = 攻击 / 爆伤 / 加成（加成显示值 = 攻击或爆伤 × 1.25）；经验消耗前期约三维的 1.5 倍，越后期比例越高
  • 轮回神力把法术冷缩加到 100% 后，再靠精血加智力堆到转冷缩上限 2000%；超出部分转「冷却之力」提最终伤害
  • 觉醒之力只加到 100%，修正也只到 100%，超出无效

计算说明

等级与神力

神力 = (等级/10)³，等级 = 10·∛神力。三次方是核心：等级 +21% ≈ 神力 +78.6%。

属性所需神力（三次曲线 · 实测定标）

单个属性从「原值」升到「目标」：K × ( S(存储值/2) − S(原值/2) )，S(x)=x(x+1)(2x+1)/6；存储值 = 面板显示值（物理/法术加成要先 ÷1.25 的轮回加成）。K 为分属性系数（2026-11-23 本人转生页 17 项实测，误差 0.000%）：攻击力/物理加成/法术加成/暴击伤害/经验加成/生命值/防御力 = 1.2e7；法术暴击率 = 2e6；金币加成/吸血 = 1.5e6；法术冷却缩短 = 2.5e5；觉醒之力 = 5e4；反震率 = 2e4；反震伤害 = 1.25e4；攻速/物理暴击率/物理暴击伤害 = 100。目标等级 = 五项成本合计开立方取整。

未来 24 小时收益（闭式）

R = 单位/1000 × 经验收益 × (3.8/4) × 1440 × 倍率；新等级 = (等级^3.8 + R)^(1/3.8)；未来24h = 新等级³ − 等级³。

转生后经验修正

当前经验修正% × (经验目标+100)/(经验原值+100)；基准常数 +100 为线性同乘区。

转生判定（计算2.0）

转生后收益 ≈ 当前平均 × (1 + 经验增长 + 输出增长/经输比)；未来24h > 转生后收益 → 不推荐转生，否则推荐转生；刚轮回不足 1 天默认不推荐转生，1-2 天仍判不准。

经验

XP = (4/3.8) × (M^3.8 − N^3.8)；时间 = XP ÷ (经验收益×单位/1000×1440×倍率)。

趋势角标（↓ 建议转生）

连续 3 天自动记录日收益，若本日增量比前一日下降 ≥20%，右上角出现「↓ 建议转生」；点角标可看近 3 天收益与增量对比。

圣法点 / 奥法

圣法点 1-85（13.0 上限 85；9.0 为 60，11.0/12.0 为 70）；奥法 1-14 阶单瓶能量逐阶提升。
