# 无限升级 · 轮回计算器（公开版）

> 一个面向《无限升级》玩家的离线/静态网页计算器：按面板数据算下一档门槛、开荒路线、神力分配与强度/奥法/圣法点等工具。

## 这是什么

- 纯静态网页（`index.html` + 静态资源），无后端、无账号、无追踪。
- 所有计算在浏览器本地完成；输入只保存在本机浏览器（localStorage）。
- 截图识别（OCR）也在浏览器本地运行，截图不会上传到任何服务器。

## 公开功能

- **开荒路线**：按当前面板给出下一档目标、门槛与缺口；
- **BOSS 数据（公开部分）**：门槛/血量/推荐路线等公开整理内容；
- **计算器**：奥法、圣法点、强度计算、撰写转换、神力加点方案；
- **攻略**：公共基础 / 法师 / 战士（公开攻略整理）；
- **截图识别（OCR，可选）**：识别挂机/面板截图中的等级、经验、修正等字段。
